# AiMatTexture

Unity demo project for AI-assisted material texture generation and replacement.

## Features

- Local ComfyUI workflow integration for basecolor, normal, and PBR texture generation.
- Online image API mode using the existing `AI Tools` API settings.
- Unity Editor dockable AI material generation window.
- Target material or selected renderer replacement workflow.
- Safe temporary generation under `Assets/Editor/AI_MaterialGenerated`.

## Notes

- API keys and local user settings are intentionally ignored by git.
- Markdown planning files are ignored; this root `README.md` is explicitly allowed.
